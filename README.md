Proyecto de automatización de pruebas para la web TodoMVC (versión JavaScript ES6) utilizando el patrón de diseño **Page Object Model (POM)**.

## 🚀 Tecnologías
* Cypress
* JavaScript
* Page Object Model (POM)

## 🧪 Pruebas incluidas
1. Alta de tareas.
2. Marcado/Desmarcado de completado.
3. Edición de tareas (vía doble clic).
4. Eliminación de tareas.
5. Filtros de estado (Active/Completed).
